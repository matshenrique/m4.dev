# Portfólio | Matheus Henrique

Portfólio em React + Vite com tema futurista roxo/neon, animações interativas (Framer Motion + canvas) e layout responsivo.

## Rodar

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera a pasta dist
```

## Personalizar

Todo o conteúdo (textos, skills e projetos) fica em `src/data.js`.

## Deploy

Conecte o repositório na Vercel ou Netlify (build: `npm run build`, saída: `dist`).
